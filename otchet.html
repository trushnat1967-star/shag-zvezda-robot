2. Назначение и состав проекта

Назначение: наглядно показать конечный цикл команд на примере робота, который по очереди собирает звёзды. Пользователь видит строку программы, действие робота и изменение счётчика.

Основной файл: index.html. Приложение выполнено как одностраничная веб-страница; отдельная установка и сборка проекта не предусмотрены.

5. Принцип работы и границы текущей версии

  1. При старте создаётся поле с выбранным количеством звёзд и правильный порядок четырёх команд.
  2. Каждое нажатие «Шаг» выполняет одну команду: робот едет к ближайшей звезде, берёт её, кладёт в рюкзак или показывает проверку поля.
  3. После четырёх команд увеличивается номер круга. После выполнения заданного количества повторов программа показывает завершение.

Важно для точного описания: команда «проверь: есть ещё?» показывает число оставшихся звёзд, но решение об остановке принимает счётчик заданного числа кругов. Это конечное повторение «N раз», не свободный цикл «пока на поле есть звёзды».

Режим поиска ошибки: кнопка выбирает один из заранее заданных неправильных порядков, а стрелки позволяют восстановить правильную последовательность.
